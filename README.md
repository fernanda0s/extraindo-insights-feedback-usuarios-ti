# extraindo-insights-feedback-usuarios-ti
Desafio Criativo: Extraindo Insights do Feedback de Usuários em Ferramentas de Gestão de Chamados de TI.

Prompt:
Analise comentários de clientes sobre o atendimento de chamados em uma ferramenta de Tíquetes gerenciada pela equipe de TI para identificar reclamações frequentes, elogios e oportunidades de melhoria.

A base contém dados de número do chamado, serviço avaliado, nota da avaliação, comentário, grupo de suporte designado, liderança responsável, analista designado, data de criação do chamado, data de resolução e data de fechamento.

Classifique os feedbacks por serviço, tipo (Incidente ou WO) e avaliação. 
Identifique os principais padrões, problemas, elogios e oportunidades de melhoria.
Aponte evidências nos dados fornecidos, utilizando os próprios comentários dos usuários.
Sugira ações prática e reais para a equipe de Governança.

O resultado será usado pela equipe de Governança para apoiar melhorias no processo de atendimento dos chamados pelos analistas.

Use apenas os dados fornecidos.
Não invente números, causas ou conclusões.
Não exponha dados que possam ferir a LGPD.
Informe suas limitações quando os dados não forem o suficiente.
Use linguagem simples para facilitar o entendimento e proporcionar a equipe que fará a consolidação compreensão do tema.
